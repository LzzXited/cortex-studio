What it is

Cortex Studio is a personal desktop tool that runs on its owner's own computer. It turns long horizontal videos into short vertical clips (with subtitles) and publishes the clips the owner selects to the owner's own TikTok, Instagram and YouTube accounts, using each platform's official API.

How it uses TikTok

  • Login Kit (user.info.basic): the owner signs in with TikTok to authorize the tool and see which account is connected.
  • Content Posting API (video.publish): at the time the owner schedules, the tool posts the selected clip, with the caption the owner wrote, directly to the owner's TikTok profile.

The tool is not offered to other people and does not access any account other than its owner's.

O que é (português)
