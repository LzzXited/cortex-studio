Privacy Policy

Last updated: September 26, 2026

What data is used

  • TikTok: the basic profile information of the connected account (open ID and display name) and the access tokens needed to publish videos.
  • Videos and captions that the owner chose to publish.

Where it is stored

All data, including access tokens, is stored only on the owner's own computer. Cortex Studio has no server and no database of its own.

How it is used

Data is used only to publish the clips the owner selected to the owner's own accounts. It is never sold, shared with third parties, or used for advertising.

Removing access and data

The owner can disconnect TikTok at any time in the tool (Settings → Connected accounts), which deletes the stored tokens, and can also revoke access in TikTok's settings (Security and permissions → Apps and services).

Política de Privacidade (português)

O Cortex Studio usa apenas as informações básicas do perfil conectado e os tokens de acesso necessários para publicar. Tudo fica guardado só no computador do dono: não existe servidor, e nenhum dado é vendido ou compartilhado. Dá para desconectar a qualquer momento no próprio Cortex Studio ou nas configurações do TikTok.
